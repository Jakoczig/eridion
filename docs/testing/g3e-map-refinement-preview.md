# ERIDION G3E experimental unsigned preview

Windows x64 requires Windows 10/11 and Microsoft Edge WebView2 Runtime. Linux x64 requires GTK 4 and WebKitGTK 6 (Ubuntu 24.04: libgtk-4-1 libwebkitgtk-6.0-4). Extract the archive and run eridion.exe / eridion from a user-owned directory. Linux may require chmod +x eridion.

Verify SHA256SUMS before running: Windows Get-FileHash -Algorithm SHA256 eridion.exe; Linux sha256sum -c SHA256SUMS. Compare README.md too. These are experimental unsigned executables, not installers or releases. No profiles, keys or credentials are included. Keep the legacy application intact.

Galaxy Map settings independently control the density and XYZ renderers. Advanced management retains signed installation, Bubble, offline controls and explicit download consent. Enabling a renderer does not permit downloads. Show Map During FSD uses the General selected-display policy. Remote viewers remain read-only over the existing paired HTTPS connection.

Gameplay/touch acceptance: enable the desired renderers; install only with explicit download consent; inspect all three projections on the laptop; test short/long routes and approaching destination; zoom through Local/Galaxy transitions; change each XYZ axis and pan, then jump and confirm framing is retained; Fit Route restores automatic framing. Test no-route charge, jump, cancel, arrival and manual dismissal on selected owner/viewer screens. Disable both renderers and confirm ordinary navigation still works. Unknown positions must stay unknown.

G3E uses fixed panel proportions and internal padding. Changing XYZ must not change any panel rectangle. Search is one local-first action, with EDSM fallback only for an authorized owner with existing consent. Fresh native windows fit a 16:9 size to the logical work area; dashboard normal dimensions and maximized state are saved. Resizing remains unrestricted.
